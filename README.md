# فِیبل.ست (FABLE.set) — فروشگاه پوشاک مردانه

سایت HTML/CSS/JS با یک سرور کوچک Node.js. **نیازی به نصب هیچ بسته‌ای نیست** (فقط Node.js).

## اجرا

1. توی VS Code پوشه `fable` را باز کن، بعد **Terminal ← New Terminal**
2. بنویس: `node server.js` و Enter بزن
3. اولین بار از تو یک **رمز مدیریت** می‌پرسد (حداقل ۶ کاراکتر) — همان را بنویس
4. مرورگر را باز کن: `http://localhost:3000`
5. برای خاموش کردن: داخل ترمینال `Ctrl + C`

از این به بعد سایت را حتماً با همین آدرس باز کن (نه با دوبار کلیک روی `index.html`).

## ورود به پنل مدیریت

۳ بار کلیک سریع روی لوگوی `fable.set` یا اضافه کردن `#admin` به آخر آدرس.
رمز روی سرور نگه‌داری می‌شود (به‌صورت هش) و داخل کد سایت نیست. بعد از ۵ بار رمز اشتباه، ۱۰ دقیقه ورود قفل می‌شود.

## امکانات پنل مدیریت

- **محصولات:** نام، قیمت، قیمت قبلی (تخفیف خودکار)، **تا ۳ عکس برای هر محصول**، **موجودی** (خالی = بدون محدودیت، ۰ = ناموجود)
- **صفحه اصلی:** اسلایدر عکس مدل‌ها (تا ۸ عکس، سرعت قابل تنظیم)، برچسب و عنوان، عکس و نام کادرهای دسته‌بندی
- **مقاله‌ها** و **متن درباره ما**
- تغییر رمز و بک‌آپ‌گیری


## کجا چی ذخیره می‌شود

| مسیر | محتوا |
|---|---|
| `data/db.json` | محصولات، درباره ما، مقاله‌ها |
| `data/admin.json` | رمز مدیر (هش‌شده) |
| `data/backups/` | بک‌آپ خودکار روزانه (۳۰ روز آخر) |
| `uploads/` | عکس‌های آپلودشده |

**برای بک‌آپ کامل، پوشه‌های `data` و `uploads` را کپی کن.**
برای بازیابی، همان دو پوشه را سر جایشان بگذار و دوباره `node server.js` بزن.

## مهم

- هر تغییری که در پنل می‌دهی روی سرور ذخیره می‌شود و همه مشتری‌ها می‌بینند.
- عکس‌هایی که از پنل آپلود می‌کنی خودکار کوچک و فشرده (webp) می‌شوند.
- برای آنلاین کردن روی هاست، سرور باید Node.js پشتیبانی کند و روی https باشد.
- فایل‌های `data` و `uploads` را روی گیت/جای عمومی نگذار.

## فایل‌ها

| فایل | نقش |
|---|---|
| `index.html` | ساختار صفحه و پنل مدیریت |
| `styles.css` | استایل‌ها |
| `script.js` | منطق فروشگاه و پنل |
| `server.js` | سرور، ورود امن، ذخیره اطلاعات، آپلود عکس |
